### 🌟 主な機能一覧

* **ガラス・仕掛け見破り（Breakable Tracker）**
  イカゲームの橋に配置された「割れるガラス」や偽物トラップを自動識別し、頭上に警告タグを表示します（検知距離の調整可能）。

* **高精度モノトーンESP**
  他プレイヤーの位置を枠線（Box）・名前・骨格（Bone）でリアルタイム表示します。

* **プレイヤー能力チェンジャー**
  移動速度（WalkSpeed）やジャンプ力（JumpPower）を自由に数値変更できるほか、姿を消す透明化（Invisible）機能も搭載しています。

* **洗練された黒白UI & アニメーション**
  起動時のスムーズなロード演出に加え、ゲームプレイの邪魔にならない折りたたみ可能なサイドパネルを採用しています。

* **R6 / R15 フル対応**
  どのようなアバター形式でも追跡・描写が崩れることなく動作します。
