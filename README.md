### 🌟 主な機能一覧

* **モノトーンESP**：距離制限に対応し、プレイヤーの枠線（Box）、名前、骨格（Bone）を画面上に正確に可視化します。
* **崩れるパーツ検知（Breakable Tracker）**：マップ内のガラスやトラップ、崩れる床などを自動検出してタグを表示します。
* **プレイヤー拡張**：移動速度（WalkSpeed）やジャンプ力（JumpPower）の動的変更、透明化機能を搭載しています。
* **アニメーションGUI**：スムーズなロード画面や、画面端に格納できる折りたたみ式コントロールパネルを実装しています。
* **マルチ環境対応**：R6 / R15 の両スケルトン構造に対応し、アバター形式を問わず動作します。
